# Seedance 2.0 提示词手册

## 先锁定，再生成

每段先确定：时长、画幅、场景布局与光线方向、重复人物/产品锚点、风格圣经、动作安全区、参考图角色、文字政策。若空间、台面、街景、舞台或产品环境会重复，先生成宽景 `SEG01_SCENE`，再生成动作关键帧。

复杂 15 秒段通常需要 3–5 张参考图：

- `SEG01_SCENE`：完整可行动空间、光线方向、主道具、人物/产品起始区、留白区。
- `SEG01_A`：开场状态/进入机位。
- `SEG01_B`：首次交接、揭示或材质特写。
- `SEG01_C`：转变中段、反应或关键物体状态。
- `SEG01_D`：高潮、出段桥接或干净定格。

每张静帧只锁定一个关键状态与运动方向；不要让单张图叙述完整 15 秒。

## 节奏和镜头链

将 15 秒视为微型序列，而非静态单镜头。推荐链条：`开场质地/状态 → 揭示或加速 → 焦点停顿（表情、材质、卖点）→ 转场桥接或干净收束`。

- 最终提示词只用整秒切片；不要使用小数秒。
- 切片数量服从实际节奏：冲击/交接可用 1 秒，反应、证明与氛围可更长；不要机械地五段各 3 秒。
- 每个切片都整合：具体动作 + 有动机运镜 + 口型/表演（如需要）+ 同期声/环境声 + 重点 SFX。
- 运镜只为叙事服务：快速推进用于揭示，甩镜用于交接，遮挡擦拭连接场景，拉焦连接手/物/脸，环绕解释物体，拉远/升降用于结尾规模感。
- 快动作后落到可读关键帧；不要每个镜头都用无理由的甩镜或推拉。

## 场景锚点提示词

```text
用途：场景连续性锚点
画幅：<比例>
创建一张宽景参考图，锁定 <地点/台面/舞台> 的完整可行动空间：<时间、环境、背景、地面/桌面、主道具>。
人物/产品锚点：<ID、外观/材质、服装/道具、比例、起始位置与活动区>。
构图：<行动安全区、标题安全留白、前中后景关系>。
光线：<主光、辅光、方向、阴影规则>。
风格：<媒介、真实感、色彩、镜头质感、材质规则>。
连续性：后续关键帧和视频保持同一空间布局、道具位置、光线方向与人物/产品身份。
不要出现可读文字、随机 Logo、水印、字幕或杂乱元素。
```

## 可直接粘贴的 Seedance 2.0 模板

标题保留模型、时长、画幅和参考图；正文不要重复这些独立字段。

```markdown
## SEG01 - <段落名>（15s / 16:9 / Seedance 2.0 / 参考图：SEG01_SCENE + SEG01_A-SEG01_D）

场景设定：<稳定空间、时间、环境状态、布局、主要道具、主光方向、动作安全区和不可漂移内容；高频人物/产品写 ID、可见发型/脸部或材质、体态/比例、服装/道具、起始位置。>
画面风格说明：
风格核心：<媒介与真实感；仅真实真人实景时可写“超写实、极致逼真、Photorealism-真人实景拍摄”。>
视觉基调：<构图、景别节奏、运动质感和氛围。>
色彩与影调：<调色、对比、饱和、高光/阴影、自然光或胶片规则。>
摄影机与镜头：<镜头感、景深、动态模糊、稳定/手持方式。>
材质与特效：<材质物理、粒子/VFX/CG 边界。>
动作质感：<速度、重量、惯性、停顿、自然表情或形变。>
风格边界：<防止媒介漂移或错误气质；不要把文字/Logo限制写在这里。>
画面与视觉连续性：<主体、构图、固定角色/产品/服装/场景/材质规则。>

动态时间切片：
(00-1s)：<开场具体动作 + 首段运镜 + 表演/口型（如有）+ 同期声/环境声 + SFX>。
(1-3s)：<揭示/交接/推进 + 机位变化 + 人物/产品互动 + 自然声音 + SFX>。
(3-6s)：<材质、表情或卖点细节 + 拉焦/停顿/跟随 + 声音延续>。
(6-10s)：<叙事/证明/情绪高潮 + 镜头收束或推进 + 反应 + 声音层次>。
(10-13s)：<转场准备或余韵 + 环境回应 + 同期声>。
(13-15s)：<桥接下一段或稳定收束 + SFX 尾音>。

生成要求：
稳定性：<人物脸部、发型、人体、服装；产品形状、比例、材质；场景布局稳定，无闪烁、无重影。>
音频：背景音乐不要生成；生成与动作自然同步的现场声、环境声、空间氛围和可见材质互动声；SFX 只强调重点，不限制其他自然声音。
字幕与文字：不要生成字幕、caption、对白文字、烧录文字、随机 logo、水印或未经授权 IP 标识；所有可读文字默认后期添加。
运动与画面：连续运动、可信物理惯性、清晰主体、稳定构图、自然表情或材质变化。
```

按实际时长删改切片：2–5 秒通常 1–3 段，10 秒约 4–6 段，15 秒按钩子、揭示、证明/反应和收束分配。切片必须是该镜头独有的描述，不能用“镜头继续完成节拍”等空话。

## 稳定性与安全边界

- 同一角色反复写相同 ID、发型/脸部特征、体态、服装、签名道具与位置；同一产品反复写形状、颜色、材质、比例与文字政策。
- 写实真人场景才使用写实锚词；动画、2D、玩具感 3D、平面动效不得混入这些锚词。
- 用安全的参考风格转移：只吸收色彩、光线、构图、镜头语言、节奏和包装规律；不复制源片主体、剧情、品牌、可识别场景或创作者风格。
- 模型中的对白仅描述口型和表演。长口播、字幕文件、配乐方案和后期说明不进入可复制提示词正文。
