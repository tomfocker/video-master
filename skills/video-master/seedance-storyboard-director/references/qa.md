# 交付前质检

## 分镜

- [ ] 每镜有时长、节拍、具体动作、景别/构图、运镜、光线/材质、连续性、声音和转场。
- [ ] 每段只有一个主导演模式；镜头链能解释观众视线如何被带动。
- [ ] 快动作后有可读停顿；没有在同一短段中塞入无关地点或剧情。
- [ ] 重复角色、产品、地点、光线方向、服装和材质规则一致。

## Seedance 2.0

- [ ] 标题含时长、画幅、模型和参考图；正文没有重复的独立元数据行。
- [ ] `场景设定` 与 `画面风格说明` 位于 `动态时间切片` 前。
- [ ] 风格说明含风格核心、视觉基调、色彩与影调、摄影机与镜头、材质与特效、动作质感、风格边界。
- [ ] 每个切片使用整秒，时长相加正确，并在同一句整合动作、运镜、表演（如有）、同期声和 SFX。
- [ ] 复杂 15 秒段有 `SCENE` 宽景锚点和足够覆盖开场、中段、收束的关键帧。
- [ ] 每段有场景/角色/产品稳定性规则，且没有闪烁、重影、漂移或不可信物理的表述。

## 声音、文字和安全

- [ ] 不生成背景音乐；提示词要求自然同期声/环境声与重点 SFX。
- [ ] 除非明确批准，不生成字幕、对白文字、可读包装、Logo、水印、地图或标牌。
- [ ] 未照搬受保护角色、真人肖像、品牌标记、原片剧情/画面或在世创作者的独特风格。
- [ ] 所有卖点和事实均来自用户提供或已确认的信息。
