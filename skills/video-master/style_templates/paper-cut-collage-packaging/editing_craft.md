# Editing Craft

## 合成顺序

1. 锁定背景底板和安全区。
2. 逐个放入 `WINDOW`、`CHAR`、`PROP`、`FX`，每层只承担一个叙事功能。
3. 统一描边、纸边、投影、色彩与运动曲线。
4. 用纸片/卡片/窗口动作完成转场，最后才加入后期文字和字幕。

## 可复用动作

| 动作 | 适合的内容功能 | 关键控制 |
| --- | --- | --- |
| 贴上/落下 | 新角色、道具、信息进入 | 有重量地停靠，不连续弹跳 |
| 推入/拉出 | 角色出场、信息替换 | 短距离，保持平面感 |
| 翻页/撕开 | 章节切换、揭示新环境 | 纸边必须是转场主体 |
| 叠放/组装 | 过程、构成、因果 | 元素按逻辑顺序落位 |
| 窗口放大 | 从讲解进入现场或故事空间 | 先保持卡片边界，再平滑扩展 |
| 遮挡擦拭 | 轻快跳转、场景转换 | 用卡片、手、道具或纸边完成 |
| 微视差 | 维持层级与活力 | 底板稳定，前后层只做轻微错位 |
| 收束定格 | 笑点、结论、情绪落点 | 给后期文字至少一秒可读时间 |

## 避免事项

- 不把所有资产烘焙成一张不可拆分的总画面。
- 不让每层都持续漂浮、旋转或闪烁。
- 不把生成模型当排版工具；所有准确文字、数值、来源和标签后期完成。
- 不为追求“剪纸感”牺牲角色比例、物件可读性或实拍真实性。
