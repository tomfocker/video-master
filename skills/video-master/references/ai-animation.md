## Routing

Choose one execution mode:

- `generative-video`: use storyboard images and model-facing video prompts; do not create code compositions.
- `hyperframes`: render the whole animation from reusable HTML/WAAPI/GSAP components.
- `hybrid`: render exact typography, charts, UI, diagrams, or overlays with HyperFrames and combine them with generated or filmed footage in post.

Record `ai_animation_enabled`, `animation_execution_mode`, `animation_engine`, and `ai_animation_modules` in `brief/spec_lock.md`. Do not treat every stylized or animated video as code animation; enable this branch only when deterministic reusable motion is wanted.

## Library layers

- Keep director methods in `style_templates/`.
- Keep executable animation assets in `ai_animation/`.
- Read `ai_animation/registry.json` before selecting a module.
- For typography, read `ai_animation/typography/catalog.json` and select only registered effect IDs.
- Treat `ai_animation/typography/catalog.json` as the source of truth. `runtime/text-effects-catalog.js` is generated by `scripts/ai_animation/build_assets.py`.
- For charts, comparisons, explainers, evidence cards, and transparent overlays, read `ai_animation/motion_templates/catalog.json` and select a registered template ID.

Current module status:

- `typography`: ready, with 12 curated Chinese-safe finite-duration WAAPI effects.
- `motion-templates`: ready, with 20 parameterized GSAP/HyperFrames compositions for data visualization, knowledge explanation, and transparent overlays.
- `spatial-camera`: ready, with an original oversized-canvas concept-map composition and smooth deterministic camera movement.
- `eagle-media`: ready, with project-local full-frame HyperFrames stages created from approved Eagle images or videos.
- `transitions`, `ui-demonstration`, and `particles-and-shaders`: planned.

Do not claim a planned module exists. Implement or explicitly mark it `Needs-Implementation` before assigning it to a production composition.

For a multi-scene concept or science explainer, read `references/ai-animation-composer.md`. Use `scripts/ai_animation/compose_explainer.py` to route structured beats to registered templates, then use `scripts/ai_animation/render_composer.py` to batch-render and assemble the final timeline. This is the normal path for reusable AI-animation videos; use the single-template initializers only for isolated scenes or overlays.

For concept, science, tutorial, and knowledge animation, also read `references/ai-animation-motion-grammar.md`. Treat its two-second motion cadence, linked transitions, point-to-point camera, depth-of-field, no-flat-slide, and continuous-interpolation rules as defaults unless the user explicitly overrides them.

## Motion template selection

Use the smallest template that expresses the shot's communication job:

- Data and trends: `bar-chart-grow`, `line-chart-draw`, `turning-point-line`, `metric-pulse`, or `number-counter`.
- Comparison and ranking: `before-after-stat`, `horizontal-bar-compare`, `stat-duel`, `status-split`, or `top-rank-list`.
- Concepts and evidence: `concept-spotlight`, `source-citation-card`, `big-number-card`, `number-impact`, or `key-point-marker`.
- Process and reasoning: `three-step-flow`, `timeline-scan`, `cause-chain`, `checklist-pop`, or `myth-fact-swap`.

Read the selected template's `design.md` and variable declaration before assigning copy. Keep one communication job per composition. Prefer `exportMode: transparent` for overlays and `exportMode: mp4` for full-frame inserts.

Initialize a selected template with:

```bash
python3 ${SKILL_DIR}/scripts/ai_animation/init_motion_template.py <project_path> --template-id concept-spotlight --variables <project_variables.json>
```

The initializer copies only the selected composition into the project, merges project variables over the bundled default preset, preserves upstream attribution, and registers the composition in `animation/ai_animation_plan.json`.

Render the registered composition with the saved project variables:

```bash
python3 ${SKILL_DIR}/scripts/ai_animation/render_motion_template.py <project_path> --composition-id concept-spotlight --format webm
```

Use `mp4` for a full-frame dark background, `webm` for a compact transparent overlay, or `mov` for a ProRes 4444 transparent editing asset. MOV conversion requires FFmpeg.

## Eagle media stages

When a user has confirmed an Eagle image or video for the project, read `references/eagle-assets.md`, register it through the official Eagle MCP plugin, then create a self-contained full-frame stage:

```bash
python3 ${SKILL_DIR}/scripts/eagle_asset_intake.py <project_path> --selected --role visual_asset
python3 ${SKILL_DIR}/scripts/ai_animation/init_eagle_media_stage.py <project_path> --asset-id <EAGLE_ITEM_ID>
python3 ${SKILL_DIR}/scripts/ai_animation/render_motion_template.py <project_path> --composition-id eagle-media-<item-id-lowercase> --format mp4
```

The stage is a new `eagle-media` module in the project plan. It copies only the confirmed source into `animation/compositions/<composition>/assets/`, keeps source attribution in `sources/eagle_assets_manifest.json`, and never writes to Eagle. Use an image stage by default; verify full renders that use local video files before delivery.

For a Composer project, include the stage in the final HyperFrames timeline after generating the Composer plan:

```bash
python3 ${SKILL_DIR}/scripts/ai_animation/init_eagle_media_stage.py <project_path> --asset-id <EAGLE_ITEM_ID> --append-to-composer --insert-after <existing-composition-id>
python3 ${SKILL_DIR}/scripts/ai_animation/render_composer.py <project_path>
```

Approved Eagle audio registered with role `background_music` is also available to `render_composer.py` and `make_animatic.py` through `sources/eagle_assets_manifest.json`. This is a project-local read of the already confirmed manifest; the render step never modifies Eagle.

The imported library is pinned to `nutllwhy/hyperframes-motion-library` commit `01c393f9f26b5b0d8432fa02682ceb36f6cc3e0f`. Preserve `motion_templates/UPSTREAM_NOTICE.md` and `motion_templates/source.json`. The upstream repository called the project open source and explicitly invited cloning, customization, and extension, but did not contain a standard license file at import time; do not relabel it as MIT or another standard license.

## Typography selection

Use one primary typography family and at most two supporting families in one short video. Prefer:

- `clean-fade-rise`, `focus-blur-rise`, `wipe-reveal`, or `typewriter-reveal` for science explainers.
- `focus-blur-rise`, `glow-impact`, or `character-rotate-in` for concept films.
- `glitch-reveal`, `zoom-impact`, and `glow-impact` only for hooks, errors, breakthroughs, or other high-energy beats.
- `clean-fade-out`, `focus-blur-out`, or `wipe-out` for matched exits.

Do not select an effect from its Chinese alias alone. Use its registered ID, energy, tone, recommended uses, and avoid list. Preserve project typography, copy, hierarchy, color, and safe areas; the effect controls motion, not art direction.

## HyperFrames usage

Copy these three files into a HyperFrames composition or reference them from their bundled paths:

```html
<link rel="stylesheet" href="text-effects.css">
<script src="text-effects-catalog.js"></script>
<script src="text-effects-runtime.js"></script>
```

Create a finite animation during composition initialization:

```js
VideoMasterTextEffects.play({
  target: "#headline",
  effectId: "focus-blur-rise",
  text: "从现象，进入原理",
  startMs: 1200,
  durationMs: 900,
  autoplay: false,
});
```

Rules:

- Keep `iterations` a finite positive integer. Never use `Infinity` in a render composition.
- Use `autoplay: false` for deterministic render initialization; HyperFrames seeks WAAPI animations through `document.getAnimations()`.
- Use `fill: both`, create animations synchronously, and avoid render-critical callbacks or timers.
- Declare the composition duration when no GSAP master timeline supplies it.
- Run HyperFrames lint/check before rendering.

Use `ai_animation/typography/examples/hyperframes-showcase.html` as a runnable composition reference, not as a visual style template.

## Project contract

When enabled, write:

```text
animation/
  ai_animation_plan.json
  compositions/
  runtime/
  renders/
qa/metadata/ai_animation_manifest.json
最终交付/08_ai_animation/
```

Initialize the project-local runtime and a finite HyperFrames composition with:

```bash
python3 ${SKILL_DIR}/scripts/ai_animation/init_project.py <project_path> --effect-id focus-blur-rise --text "从现象，进入原理"
```

Treat the generated composition as a project scaffold. Replace its layout and copy according to the locked art direction while keeping registered effect IDs and deterministic timing.

For a registered motion template, use `init_motion_template.py` instead. Keep its copied `package.json`, project preset, source metadata, and upstream notice with the composition.

Open the generated `animation/index.html?autoplay=1` for a quick ordinary-browser preview. Omit `autoplay=1` for HyperFrames rendering so the runtime owns the playhead.

Minimum `animation/ai_animation_plan.json`:

```json
{
  "schema_version": 1,
  "enabled": true,
  "engine": "hyperframes",
  "execution_mode": "hyperframes",
  "modules": ["typography"],
  "typography": {
    "effects": [
      {
        "element_id": "main_title",
        "effect_id": "focus-blur-rise",
        "text_source": "script/script.md",
        "start_ms": 1200,
        "duration_ms": 900
      }
    ]
  },
  "compositions": [
    {
      "id": "main",
      "source": "animation/index.html",
      "duration_seconds": 30,
      "aspect_ratio": "16:9"
    }
  ]
}
```

The final manifest must set `ai_animation: true`, reference the plan, name the engine, and list each delivered composition with an existing source and rendered output path.

## Library maintenance

After editing `typography/catalog.json`, run:

```bash
python3 ${SKILL_DIR}/scripts/ai_animation/build_assets.py
python3 ${SKILL_DIR}/scripts/ai_animation/validate_library.py
```

Preserve `ai_animation/typography/THIRD_PARTY_NOTICES.md` and the bundled MIT license when copying or distributing the typography runtime.

For the motion library, keep the original template IDs stable and run the same validator after any import or template edit. Preserve `ai_animation/motion_templates/UPSTREAM_NOTICE.md` and `source.json`; update the pinned commit only after reviewing upstream changes and permission metadata.
