# AI Animation

Use this branch when AI selects and assembles deterministic code animation instead of asking a generative video model to synthesize every frame.

## Routing

Choose one execution mode:

- `generative-video`: use storyboard images and model-facing video prompts; do not create code compositions.
- `hyperframes`: render the whole animation from reusable HTML/WAAPI/GSAP components.
- `hybrid`: render exact typography, charts, UI, diagrams, or overlays with HyperFrames and combine them with generated or filmed footage in post.

Record `ai_animation_enabled`, `animation_execution_mode`, `animation_engine`, and `ai_animation_modules` in `brief/spec_lock.md`. Do not treat every stylized or animated video as code animation; enable this branch only when deterministic reusable motion is wanted.

## Library layers

- Keep director methods in `style_templates/`.
- Keep executable animation assets in `ai_animation/`.
- Read `ai_animation/registry.json` before selecting a module.
- For typography, read `ai_animation/typography/catalog.json` and select only registered effect IDs.
- Treat `ai_animation/typography/catalog.json` as the source of truth. `runtime/text-effects-catalog.js` is generated by `scripts/ai_animation/build_assets.py`.

Current module status:

- `typography`: ready, with 12 curated Chinese-safe finite-duration WAAPI effects.
- `spatial-camera`, `transitions`, `data-visualization`, `diagram-motion`, `ui-demonstration`, and `particles-and-shaders`: planned.

Do not claim a planned module exists. Implement or explicitly mark it `Needs-Implementation` before assigning it to a production composition.

## Typography selection

Use one primary typography family and at most two supporting families in one short video. Prefer:

- `clean-fade-rise`, `focus-blur-rise`, `wipe-reveal`, or `typewriter-reveal` for science explainers.
- `focus-blur-rise`, `glow-impact`, or `character-rotate-in` for concept films.
- `glitch-reveal`, `zoom-impact`, and `glow-impact` only for hooks, errors, breakthroughs, or other high-energy beats.
- `clean-fade-out`, `focus-blur-out`, or `wipe-out` for matched exits.

Do not select an effect from its Chinese alias alone. Use its registered ID, energy, tone, recommended uses, and avoid list. Preserve project typography, copy, hierarchy, color, and safe areas; the effect controls motion, not art direction.

## HyperFrames usage

Copy these three files into a HyperFrames composition or reference them from their bundled paths:

```html
<link rel="stylesheet" href="text-effects.css">
<script src="text-effects-catalog.js"></script>
<script src="text-effects-runtime.js"></script>
```

Create a finite animation during composition initialization:

```js
VideoMasterTextEffects.play({
  target: "#headline",
  effectId: "focus-blur-rise",
  text: "从现象，进入原理",
  startMs: 1200,
  durationMs: 900,
  autoplay: false,
});
```

Rules:

- Keep `iterations` a finite positive integer. Never use `Infinity` in a render composition.
- Use `autoplay: false` for deterministic render initialization; HyperFrames seeks WAAPI animations through `document.getAnimations()`.
- Use `fill: both`, create animations synchronously, and avoid render-critical callbacks or timers.
- Declare the composition duration when no GSAP master timeline supplies it.
- Run HyperFrames lint/check before rendering.

Use `ai_animation/typography/examples/hyperframes-showcase.html` as a runnable composition reference, not as a visual style template.

## Project contract

When enabled, write:

```text
animation/
  ai_animation_plan.json
  compositions/
  runtime/
  renders/
qa/metadata/ai_animation_manifest.json
最终交付/08_ai_animation/
```

Initialize the project-local runtime and a finite HyperFrames composition with:

```bash
python3 ${SKILL_DIR}/scripts/ai_animation/init_project.py <project_path> --effect-id focus-blur-rise --text "从现象，进入原理"
```

Treat the generated composition as a project scaffold. Replace its layout and copy according to the locked art direction while keeping registered effect IDs and deterministic timing.

Open the generated `animation/index.html?autoplay=1` for a quick ordinary-browser preview. Omit `autoplay=1` for HyperFrames rendering so the runtime owns the playhead.

Minimum `animation/ai_animation_plan.json`:

```json
{
  "schema_version": 1,
  "enabled": true,
  "engine": "hyperframes",
  "execution_mode": "hyperframes",
  "modules": ["typography"],
  "typography": {
    "effects": [
      {
        "element_id": "main_title",
        "effect_id": "focus-blur-rise",
        "text_source": "script/script.md",
        "start_ms": 1200,
        "duration_ms": 900
      }
    ]
  },
  "compositions": [
    {
      "id": "main",
      "source": "animation/index.html",
      "duration_seconds": 30,
      "aspect_ratio": "16:9"
    }
  ]
}
```

The final manifest must set `ai_animation: true`, reference the plan, name the engine, and list each delivered composition with an existing source and rendered output path.

## Library maintenance

After editing `typography/catalog.json`, run:

```bash
python3 ${SKILL_DIR}/scripts/ai_animation/build_assets.py
python3 ${SKILL_DIR}/scripts/ai_animation/validate_library.py
```

Preserve `ai_animation/typography/THIRD_PARTY_NOTICES.md` and the bundled MIT license when copying or distributing the typography runtime.
