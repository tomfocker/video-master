# 导演模式库

每个镜头或段落只选一个主模式。先锁定角色、产品、地点、风格与资产角色，再将下列节奏写成具体的画面、镜头与声音；不要把模式名称原样塞进提示词。

## 通用规则

- 为每份资产标明用途：场景锚点、首帧、尾帧、人物、产品、动作、节奏或延展源。
- 支持 `@图片` / `@视频` 的工作流中，明确说明其角色，例如“`@图片1` 作为产品外观参考”。
- 每段保留一个清晰的视觉因果链；不要在数秒内更换无关地点、人物、产品与风格。
- 每镜保留自然同期声/室内或环境底噪，另加一到两个重点 SFX；多镜项目不在单段生成背景音乐。

| 模式 | 适用情况 | 节奏语法 | 必须锁定 |
| --- | --- | --- | --- |
| 产品展示 | 电商、产品广告、上市片 | 材质/轮廓入场 → 微距证明 → 使用/转动/拆装 → 干净 hero 定格 | 形状、颜色、材质、比例、Logo/文字政策 |
| 直播口播 | 主播/模特展示产品 | 快速钩子 → 手/脸/产品证明 → 使用特写 → 反应 → CTA 安全定格 | 主播、手部动作、卖点边界、字幕政策 |
| 短剧反转 | 冲突、喜剧、情绪故事 | 冲突钩子 → 证据/动作升级 → 特写反应 → 反转 → 停顿/离场 | 人物关系、服装、场景、反转道具 |
| 奇幻动作 | 武侠、魔法、战斗 | 蓄势静止 → 加速/出招 → 碰撞 → 粒子桥接 → 英雄姿态 | 原创角色、武器、能量颜色、暴力尺度 |
| 科学可视化 | 教育、机制、工业流程 | 建立系统 → 进入机制 → 因果变化 → 前后对照 → 稳定解释定格 | 已核实事实、可视化隐喻、合规边界 |
| 节拍蒙太奇 | MV、穿搭、旅行、海报切换 | hero 状态 → 节拍切换 → 镜头/造型变化 → 收束定格 | 节拍数、顺序、转场类型、参考图角色 |
| 一镜到底 | 连续移动、参观、空间穿行 | 首帧锚定 → 跟随路径 → 遮挡转场 → 到达揭示 → 尾帧定格 | 起止帧、无剪辑、遮挡物、可解释路径 |
| 视频延长 | 向前/向后扩展旧片段 | 接住原边界 → 一个新变化 → 细节/反应 → 新边界 | 源视频、延长方向、原镜头/光线/动作 |
| 视频编辑 | 保留原片、替换一个元素 | 保持原机位/时序 → 引入改变 → 保持空间关系 → 改写收束 | 必须保留项、唯一改动项、替换资产 |
| 动态海报 | 海报动效、标题安全画面 | 固定主视觉 → 有序揭示 → 轻微材质/光效 → 留白定格 | 源海报、元素顺序、镜头克制、文字后期 |
| 动画动作 | 2D/3D 角色、吉祥物 | 清楚姿势 → 预备 → 动作弧 → 冲击/反应 → 可读定格 | 角色设定、比例、服装、表情与动作阶段 |

## 产品展示变体

- **科技精密**：只展示产品相关的部件、切面、扫描光与重组；避免把美妆、食品或奢侈品硬做成爆炸视图。
- **美妆生活方式**：质地微距、手部使用、肤感光泽、瓶身扫光、干净梳妆台 hero。
- **食品材质**：倒入、切开、蒸汽、脆响、冷凝、食材落点；材质要符合实际，不制造脏污或解剖感。
- **服饰穿搭**：面料运动、穿搭切换、局部细节、全身造型定格。
- **奢侈静物**：克制转台、反射控制、负空间、缓慢扫光与安静停顿。

## 结构提示

- **转场**：用门边、布料、蒸汽、手、车辆、物体掠过、阴影或光斑等物理遮挡连接空间；一镜到底不可同时要求硬切。
- **动作**：高速动作和冲击后，安排拉焦、停顿或 hero pose，避免全段持续摇晃。
- **人物**：反复使用相同的角色 ID、发型/脸部特征、体态、服装、道具和起始位置；不要在中段悄然换人。
- **文字**：用“留标题安全区”代替让模型排版；所有可读文字默认后期添加。
